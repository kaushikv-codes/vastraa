# Vastraa 🛍️
> AI Fashion Try-On & Occasion Styling Platform

India's AI-powered fashion platform — virtual try-on + occasion-based outfit discovery for consumers, and a B2B SaaS dashboard for fashion brands.

## Tech Stack
- **Backend:** Python (Flask), PostgreSQL (Supabase)
- **Frontend:** Next.js 14, Tailwind CSS
- **AI:** Fashn.ai (virtual try-on), OpenAI GPT-4o (style recommendations)
- **Payments:** Razorpay
